# Consulting Client Onboarding

**Workspace:** use the selected project and its `AGENTS.md`; keep existing entity folders and
Reality headings. Business paths below are relative to that project. Bundled resources are relative
to this installed skill; sibling capabilities resolve by their installed names. Never search another
private checkout for missing inputs. Use workspace identity, audience, pricing, and `DESIGN.md` fonts.

## Steps
1. Copy `clients/_TEMPLATE/` → `clients/{client}/` (full lifecycle subfolders).
2. Fill the dashboard `AGENTS.md`: status, engagement/value, champion, stakeholders, stakes, dates, next action.
3. Move the deal folder from `pipeline/` into the new client folder (artifacts: discovery → `01-discovery/`, proposal → `02-proposals/`).
4. Generate the kickoff checklist: SOW signed, first invoice, Slack Connect, repo provisioned, designated contacts, 48h-decision SLA.
5. Update `pipeline/_board.md`, the CRM stage (Closed Won), and `business/metrics/dashboard.html`.
6. Propose the maintenance/retainer tier before delivery even starts.
